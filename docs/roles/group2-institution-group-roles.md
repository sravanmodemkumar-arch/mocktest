# EduForge — Group 2: Institution Group Level Roles

> Institution Groups are chains/trusts that own and operate multiple schools/colleges.
> Examples: Narayana Group, Sri Chaitanya, Vidya Niketan, District Educational Trusts.
> Scale: 150 groups · each group owns 5 to 50 branches · total ~1,900 institutions under groups.

---

## What a Group Manages

| Function | Scope |
|---|---|
| Academic standardization | Same syllabus, same exam pattern across all branches |
| Centralized finance | Fee collection, audits, EduForge subscription billing |
| HR & staff transfers | Hire centrally, post to branch, transfer between branches |
| Compliance | BGV for all staff, POCSO, DPDP across every branch |
| IT & portals | All branch portals configured under one group umbrella |
| Admissions | Centralized admission campaign, branch-wise seat allocation |
| Hostel management | Policy, welfare standards, warden supervision across branches |
| Transport | Fleet, routes, GPS tracking across all branches |
| Analytics & MIS | Cross-branch performance comparison, weak branch identification |
| Internal audit | Annual inspection of every branch |
| Legal | Land, buildings, trust deed, regulatory filings |
| Marketing | Group brand, admissions campaigns, social media |

---

## System Access for Group Roles

| Level | Label | Who |
|---|---|---|
| G0 | No Platform Access | Marketing, HR, Admin, Legal (internal tools only) |
| G1 | Group Read Only | View all branch dashboards, analytics, MIS — no edits |
| G2 | Group Content | Manage group-level content library shared to all branches |
| G3 | Group Operations | Manage staff, students, fees, exams across all branches |
| G4 | Group Admin | Configure all branch portals, users, roles under the group |
| G5 | Group Super Admin | Full access to every branch under this group |

## Group 2 vs Branch (Group 3) — Key Difference

| Action | Group Level | Branch Level |
|---|---|---|
| Create a branch portal | Group IT Admin ✅ | Branch Principal ❌ |
| Hire a teacher | Group HR Manager ✅ | Branch Principal ✅ (within budget) |
| Transfer a teacher | Group HR / Transfer Coord ✅ | Branch Principal ❌ |
| Set fee structure | Group Finance Director ✅ | Branch Accountant ❌ |
| Set exam calendar | Group Exam Controller ✅ | Branch Exam Coord ✅ (local tests only) |
| View all branches' results | Group Academic MIS ✅ | Branch Principal ❌ (own branch only) |
| Approve scholarship | Group Scholarship Mgr ✅ | Branch Principal (recommend only) |
| BGV a new staff | Group BGV Coordinator ✅ | Branch cannot do BGV alone |
| Raise EduForge support ticket | Group Billing Coordinator ✅ | Branch IT Admin (limited) |
