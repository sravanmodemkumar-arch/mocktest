# Division C — Group Admissions: Page Index

## Division Overview

Division C covers the full Group Admissions function for EduForge — every workflow from initial student enquiry to final enrollment confirmation, scholarship award, demo class coordination, and alumni engagement. The division serves seven G3-level roles: Group Admissions Director, Group Admission Coordinator, Group Admission Counsellor, Group Scholarship Exam Manager, Group Scholarship Manager, Group Alumni Relations Manager, and Group Demo Class Coordinator. All Division C pages operate under the URL prefix `/group/adm/` and are scoped to group-level data aggregated from all branches. Branch-level admission operations (individual applications, branch seat matrices, branch counsellor queues) are managed in branch-level modules; Division C provides the group leadership layer that oversees, coordinates, and reports on those branch operations across the entire institution.
