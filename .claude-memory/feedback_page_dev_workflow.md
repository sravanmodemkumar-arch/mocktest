Write pages one by one in sequence. Cover ALL functionality for each page — full depth, full features, all roles, all edge cases. Can add extra roles or pages if needed to ensure complete coverage.

**Why:** User wants production-quality specs that a developer can implement directly, with no gaps. "Think deeply" = 50+ years of experience depth standard. Adding roles/pages is allowed if they are genuinely needed for functional completeness.

**How to apply:**
- Never skip sections or trim detail to save space
- After completing all pages in a Division, move to the next Division
- After completing all Divisions in Group 2, move to Group 3 and repeat the same structure (roles sheet → page index → individual page specs)
- Write pages sequentially — do not jump ahead or batch-write multiple pages simultaneously unless explicitly asked
